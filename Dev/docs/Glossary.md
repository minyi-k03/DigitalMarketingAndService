# 구독컷 (SubCut) 도메인 용어집 (v1.4 최종 완결본)

대학생·청년층이 무료체험을 안전하게 탐색·추적하고 원치 않는 유료 전환 직전에 해지 가이드라인과 최단 직링크로 탈출하도록 돕는 한편, B2B 파트너사에게 초기 체험단 유입과 이탈 사유 데이터를 제공하는 양면 시장 플랫폼.

## 1. 카탈로그 및 양면시장 (Catalog & Marketplace)

**CatalogItem (카탈로그 항목)**:
구독컷이 해지 진입 경로, 단계별 해지 가이드라인, 기본 무료체험 일수, 잔여 기간 유지 정책을 사전 검증하여 등록해 둔 구독형 소프트웨어 및 멤버십 단위.
*Avoid*: 서비스, 앱, 툴, 상품

**GuardedService (방어 대상 서비스)**:
B2C 사용자 유입과 락인을 위해 운영자가 직접 해지 경로와 가이드라인을 구축해 제공하는 대중적 빅테크·AI·배달·OTT·클라우드·학습 카탈로그 항목.
*Avoid*: 일반 서비스, 미끼 상품, 비제휴 툴

**SponsoredTrial (제휴 피처드 체험)**:
초기 사용자 확보와 이탈 데이터 수집을 목적으로 B2B 파트너사가 비용을 지불하고 전용 라운지 및 피처드 슬롯에 노출하는 카탈로그 항목.
*Avoid*: 광고 상품, 입점 서비스, 유료 툴

**Partner (파트너사)**:
자사 소프트웨어를 제휴 피처드 체험으로 등록하거나 이탈 분석 리포트를 구매하는 B2B 스타트업 고객.
*Avoid*: 광고주, 클라이언트, 개발사

**DarkPatternLevel (다크패턴 난이도)**:
카탈로그 항목의 해지 메뉴 숨김 깊이, 설득 팝업 반복 횟수, PC 접속 강제 여부 등 절차적 복잡도를 상·중·하로 등급화하여 탐색 카드에 표시하는 지표.
*Avoid*: 해지 별점, 위험도, 악성 지수

**EduBenefit (학술 무료 혜택)**:
일반 유료 전환형 무료체험 대신 학교 웹메일(`@ac.kr`) 재학생 인증을 통해 졸업 시까지 무료 라이선스나 학생 할인을 받을 수 있는 카탈로그 항목의 대체 플랜 안내 정보.
*Avoid*: 학생 할인 쿠폰, 교육용 광고, 에듀 프로모션

## 2. 구독 추적 및 일정 (Tracking & Schedule)

**TrialRecord (체험 기록)**:
사용자가 특정 카탈로그 항목의 무료체험 시작일과 체험 일수를 지정하여 생성한 개별 추적 건.
*Avoid*: 구독 내역, 신청서, 트래킹 아이템

**BillingDate (공식 결제 예정일)**:
무료체험 시작일에 체험 일수를 단순 합산한 달력상의 유료 전환일.
*Avoid*: 만료일, 종료일, 결제일

**SafeEndDate (안전 만료일)**:
해외 시차(UTC/PST)나 시간 단위 정산으로 인한 조기 결제 사고를 막기 위해 공식 결제 예정일에서 안전 버퍼(글로벌 서비스 1일 차감)를 적용한 구독컷 기준 D-Day.
*Avoid*: 권장 해지일, 버퍼 만료일, 실제 D-Day

**EscapeAlert (탈출 알림)**:
안전 만료일 도래 전(D-3, D-1) 사용자에게 카카오톡으로 발송하는 사전 해지 경고 메시지.
*Avoid*: 푸시 알림, 리마인더, 경고톡

**CancelAttempted (해지 시도 상태)**:
사용자가 해지 브릿지에서 1초 이탈 투표를 마치고 해지 최단 직링크로 이동했으나, 외부 사이트 내 로그인 초기화·설득 팝업·PC 접속 강제 장벽으로 인한 해지 실패 가능성에 대비해 최종 완료 확정 전까지 유지하는 체험 기록의 중간 상태.
*Avoid*: 가해지, 해지 대기, 임시 취소

## 3. 해지, 사후 구제 및 B2B 데이터 (Offboarding, Recovery & Analytics)

**EscapeBridge (해지 브릿지)**:
탈출 알림을 클릭한 사용자가 외부 사이트로 이동하기 직전에 거치는 구독컷의 가이드 화면으로, 해당 서비스의 단계별 해지 가이드라인(치트시트), 사전 백업 체크리스트, 1초 이탈 투표, 해지 최단 직링크를 한눈에 제공한다.
*Avoid*: 중간 페이지, 랜딩 페이지, 단순 리다이렉트 창

**EscapePattern (해지 경로 유형)**:
외부 서비스의 다크패턴 및 결제 구조에 따라 해지 브릿지가 제공하는 우회 안내 방식의 분류(플랫폼·계정 직링크 이동형, SPA 모달·심층 메뉴 가이드형, PC 웹·전용 앱 강제 우회형).
*Avoid*: 링크 타입, URL 종류, 해지 옵션

**EscapeGuide (해지 가이드라인)**:
외부 서비스 접속 후 마주치는 숨겨진 메뉴 경로, 반복되는 설득 팝업 회피법, '즉시 해지 vs 다음 달 갱신 취소' 선택 기준, 인앱 브라우저 로그인 우회법 등을 3단계 이내의 행동 지침으로 요약한 다크패턴 돌파 매뉴얼.
*Avoid*: 사용 설명서, FAQ, 고객센터 안내문

**EscapeLink (해지 최단 직링크)**:
외부 서비스의 구조적·보안적 한계(대리 해지 불가, 로그인 초기화, 모달 구조 등) 내에서 사용자가 해지 화면에 가장 가까운 진입점(계정 설정 페이지, 앱마켓 정기결제 관리 허브, 전용 앱 딥링크)으로 즉시 접속할 수 있도록 연결하는 URL.
*Avoid*: 자동 해지 버튼, 대리 취소 API, 외부 링크

**AccessRetentionPolicy (잔여 기간 유지 정책)**:
중도 해지 신청 시 남은 무료체험 기간의 이용 권한이 만료일까지 유지되는지(갱신 취소형) 혹은 해지 즉시 박탈되는지(즉시 종료형)를 구분하여 사전 해지 적기를 안내하는 카탈로그 규칙.
*Avoid*: 해지 효력, 즉시 탈퇴 여부, 일할 계산 규칙

**BackupChecklist (사전 백업 가이드)**:
해지 즉시 계정이 정지되거나 작업물(문서, 디자인, 클라우드 사진 등) 접근이 차단되는 카탈로그 항목에 대해 해지 직전 데이터 백업 경로를 안내하는 체크리스트.
*Avoid*: 데이터 다운로드 창, 파일 백업 툴, 스토리지 알림

**ExitPoll (1초 이탈 투표)**:
사용자가 해지 최단 직링크로 이동하기 위해 해지 브릿지에서 단 한 번의 클릭으로 응답하는 정량적 해지 사유 설문.
*Avoid*: 해지 설문조사, 피드백 폼, 리뷰

**ExitReason (표준 이탈 사유)**:
동일 카테고리 내 서비스 간 정량 비교를 위해 1초 이탈 투표에 공통 적용되는 5대 해지 원인(가격 부담, 기능·성능 부족, 사용성·UI 복잡, 단기 목적 달성, 대체 서비스 이동).
*Avoid*: 설문 문항, 해지 코멘트, 불만 사항

**RefundTemplate (환불 요청 템플릿)**:
무료체험 해지 시점을 놓쳐 원치 않는 자동 결제가 발생한 사용자가 고객센터에 즉시 복사해 발송할 수 있는 국문·영문 맞춤형 청약철회 요청 양식.
*Avoid*: 환불 대행, 자동 결제 취소, 소비자원 신고서

**BrokenLinkReport (경로 오류 제보)**:
외부 서비스의 UI 개편으로 인해 해지 최단 직링크나 해지 가이드라인이 실제 화면과 다를 때, 로그인 세션을 보유한 실사용자가 해지 브릿지에서 원클릭으로 운영자에게 수정을 요청하는 크라우드소싱 피드백.
*Avoid*: 버그 리포트, 크롤링 에러, 고객센터 문의

**SavedAmount (누적 방어 금액)**:
사용자가 안전 만료일 이전에 해지를 확정하여 원치 않는 자동 결제로부터 지출을 막아낸 월 구독료의 합산 통계 금액.
*Avoid*: 절약 포인트, 환급금, 아낀 돈

**AlternativeMatch (제한적 대안 매칭)**:
해지 완료 후 사용자의 표준 이탈 사유가 대안 수요 조건에 부합할 때만(단기 목적 달성 제외) 주 1회 이하의 빈도 제한을 두어 비침투적 배너로 제안하는 제휴 피처드 체험 추천 규칙.
*Avoid*: 팝업 광고, 강제 추천, 리타겟팅

**ChurnReport (이탈 분석 리포트)**:
특정 카탈로그 항목의 1초 이탈 투표 응답과 전환 지표를 카테고리 평균과 비교·분석하여 파트너사에게 판매하는 B2B 데이터 상품.
*Avoid*: 통계 자료, 피드백 요약본, 결과 보고서

## 4. 핵심 아키텍처 결정 기록 (ADR 요약)

1. **`ADR-0001` 해지 브릿지(`EscapeBridge`) 경유 및 가이드·투표 결합**:
   외부 사이트의 대리 해지 불가 및 다크패턴 장벽(설득 팝업, 모달 메뉴, 로그인 풀림)을 해결하기 위해, 알림톡에서 외부 URL로 바로 이동시키지 않고 내부 `EscapeBridge`를 먼저 거친다. 이를 통해 `EscapeGuide`(3줄 돌파 가이드라인)를 숙지시키고 `ExitPoll`(1초 이탈 투표) 응답률 100%를 확보한 뒤 `EscapeLink`로 연결한다.

2. **`ADR-0002` 글로벌 SaaS 대상 1일 차감 안전 만료일(`SafeEndDate`) 도입**:
   가입 시각(시/분)을 입력받지 않는 '1초 간편 등록' UX를 유지하면서 해외 결제 시차로 인해 D-1에 조기 결제되는 사고를 원천 차단하기 위해, 글로벌 카탈로그 항목은 공식 결제 예정일(`BillingDate`)에서 1일을 차감한 `SafeEndDate`를 D-Day로 산정한다.

3. **`ADR-0003` 해지 직링크 이동과 최종 완료의 2단계 상태 분리(`CancelAttempted`)**:
   사용자가 `EscapeLink`로 이동하더라도 외부 사이트의 PC 접속 강제나 비밀번호 분실로 해지를 끝내지 못할 수 있으므로, 즉시 해지 완료로 종결하지 않고 `CancelAttempted` 상태를 거쳐 미확정 시 D-1에 최종 확인 알림을 1회 더 발송한다.

4. **`ADR-0004` 신용카드 연동(`Rocket Money` 방식) 대신 금융 무연동 사전 예방 채택**:
   민감한 카드 정보 연동에 대한 대학생의 진입장벽을 없애고, 첫 달 유료 결제가 승인된 후에야 사후 감지되는 결제 내역 기반 모델의 한계를 극복하기 위해 카탈로그 선택만으로 사전 방어하는 무연동 모델을 채택한다.

5. **`ADR-0005` 크롤링 대신 실사용자 오류 제보(`BrokenLinkReport`) 기반 경로 유지보수**:
   외부 서비스의 해지 화면은 로그인 세션과 구독 활성 상태가 필수여서 봇 크롤링이 구조적으로 불가능하므로, 해지를 진행 중인 실사용자의 원클릭 제보(`BrokenLinkReport`)와 운영자 DB 핫픽스로 최신성을 유지한다.
